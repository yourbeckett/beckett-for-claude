# Start with beckett

1. If no beckett tools are available, beckett isn't connected yet. Give the steps and stop:
   - In Claude chat or Cowork: open **Customize > Plugins**, choose **beckett**, and select **Connect** on the **Connectors** tab.
   - In Claude Code: run `/mcp`, choose **beckett**, and sign in.
   - Signing in creates a beckett account for anyone who doesn't have one, with a free week and no card.
2. If it is connected, ask what they'd like to keep track of first, and offer a few places to start:
   - set up a project, such as a trip or a room to repaint, with a checklist and tasks
   - plan next week's dinners and build the grocery list
   - save a note about someone or something they don't want to forget
3. Do the one they pick, following the shared rules in the use-beckett skill.
